# Facial memory try-out

A prototype facial memory test for the Glahn and Mathias labs, running in a web
browser: <https://crackedbassoon.com/braindeck-tryout/>

1. Use a laptop or tablet with Chrome, Safari or Firefox. Turn the sound on:
   the instructions are spoken as well as shown.
2. The battery (`facial-memory-en`, or `facial-memory-es` for Spanish) and the
   task (Facial Memory) are already chosen.
3. Type a participant ID of one to three capital letters followed by two to
   five digits, for example `TRY01`, press **Start Run**, then **Begin run 1**.
   Use a new ID for each try: this build holds only the first set of faces.
4. Learn 20 faces, then answer **Yes** or **No** for 80 faces by clicking,
   touching, or pressing the left and right arrow keys.

This try-out sends nothing anywhere: results stay in your browser. If the page
reloads in the middle of a run, enter the same ID and press **Start Run** to
carry on where you left off.

Built from BrainDeck 0.2.0 (commit f61d6c4), 20 November 2026.
